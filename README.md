## Сделать веб-форму
### Для этого необходимо 
- административной части необходимо перейти в Сервисы -> Веб-формы -> Настройки форм
- нажать кнопку Создать
- в появивщейся форме заполнить поля 
  (
    Наименование: Сбор заявок, 
    Название ссылки на результаты: Заявка,
    Подпись на кнопке, сохраняющей результаты формы: Оставить заявку)
- на вкладке Описание введите текст "Наши сотрудники помогут выполнить подбор услуги и расчет цены с учетом ваших требований"
- нажмите кноку Применить
 - на этой же странице кликните на кнопку Вопросы
Далее необходимо добавить вопросы, нажимая на кнопку Добавить и заполняя поля
1. Вопрос: "Ваше имя", Тип поля для ответа: Строка, Добавить валидатор на длину строки от 3 до 25
2. Вопрос: "Компания/Должность", Тип поля для ответа: Строка, Добавить валидатор на длину строки от 3 до 255
3. Вопрос: "Email", Тип поля для ответа: Email
4. Вопрос: "Номер телефона", Тип поля для ответа: Строка, Добавить валидатор на длину строки от 10 до 12
5. Вопрос: "Сообщение", Тип поля для ответа: Текст

Все вопросы, кроме Сообщение, пометить как обязательные. 

### Теперь создадим страницу для отображения формы.
 - административной части необходимо перейти в Контент -> Структура сайта -> Файлы и папки
 - нажать Добавить -> Добавить папку
 - в форме ввести следующие данные: 
   - Название раздела "Услуги"
   - Выключить генерацию названия папки из названия раздела 
   - Имя папки: services
   - оставить галочку "Создать пункт меню"
 - нажать Сохранить

Мы перешли в Редактирование страницы
- найти в списке компонент form.result.new или "Заполнение веб-формы"
- перенести его на страницу -> откроется окно настройки компонента
- в ID веб-формы необходимо выбрать созданную ранее веб-форму
- Сохранить -> Сохранить
- перейти на публичную часть сайта ->  меню должен появиться пункт Услуги -> сли клинкуть, то перейдем на страницу с созданной формой

Если заполнить поля и отправить заявку, то ее можно увидеть Сервисы -> Веб-формы -> Результаты -> Заявка

## Сделать шаблон компонента form.result.new, интегрированный с формой
Шаблон находится в папке src\local\templates\.default\components\bitrix\form.result.new\medicine

- В административной части зайдите по адресу Контент\Структура сайта\Файлы и папки\local\templates\.default\components\bitrix\form.result.new\medicine
- если каких-либо папок нет, то создайте их.
- В папку medicine скопируйте все содеримое из папки medicine (в репозитарии)
- перейдите в Контент\Структура сайта\Файлы и папки\services
- в контекстном меню у файла index.php выбрать "Редактировать как HTML"
- дважды кликнуть на компонент Заполнение веб-формы
- в выпадающем списке "Шаблон компонента" необходимо выбрать medicine (Общий шаблон)
- снять галочку "Игнорировать свой шаблон"
- Сохранить -> Сохранить
- вернуться на публичную часть сайта и перейти в раздел Услуги. К форме применился новый шаблон
